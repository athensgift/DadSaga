# ADR-0001: Record architecture decisions

**Status:** Accepted

## Context
This is a solo portfolio project. Reviewers (and future me) should be able to see *why* things are the way they are.

## Decision
Record significant decisions as short ADRs in `docs/adr/`, numbered sequentially: Context → Decision → Consequences.

## Consequences
Decisions are explicit and reviewable. ADRs are never edited after acceptance; a new ADR supersedes an old one.
